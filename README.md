# scpc1-viz

SCPC 2026 AI 챌린지 1차 예선(AI Agent Harness) 문제를, 입력 하나가 6칸 답안이 되는 과정으로 풀어 보여주는 스크롤 설명 페이지입니다.

- 예시 문제는 대회 데이터가 아닙니다. 같은 구조로 새로 만든 가상 값입니다.
- 결론은 작성자의 하네스에 같은 입력을 돌린 결과입니다.
- 휠, 스와이프, ↑↓ 키 한 번에 한 단계씩 넘어갑니다.

## 실행

정적 파일이라 빌드가 필요 없습니다.

```bash
python3 -m http.server 8000
```

http://localhost:8000 을 여세요.

## 구성

- `index.html`: 화면 뼈대
- `css/style.css`: 스타일
- `js/data.js`: 가상 예시 문제와 단계별 문구
- `js/main.js`: 단계 전환, 강조, 화살표
- GSAP 3 (CDN)
